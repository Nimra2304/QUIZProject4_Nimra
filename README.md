# 3-Question Quiz Game (Python)

An interactive command-line application built in Python that challenges users with general knowledge questions, tracks their live score, and evaluates their performance. Designed to demonstrate fundamental program control flow and user input handling.

---

## 🛠️ Features

* **Dynamic Score Tracking:** Keeps a running counter (`+1` point per correct answer) and reports the final score at the end.
* **Interactive CLI Interface:** Sequential question prompts with immediate feedback on correct or incorrect answers.
* **Flexible Input Matching:** Handles answer evaluation smoothly regardless of user capitalization or extra whitespace (`.lower()` and `.strip()`).
* **Educational Core:** Built specifically to practice conditional decision-making and variable management in Python.
